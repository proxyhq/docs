# Cards

A **Card** is a virtual spending instrument issued to an agent.

## Card Types

| Usage | Description |
|-------|-------------|
| `single` | One-time use, auto-closes after first transaction |
| `multi` | Reusable for multiple transactions |

## Card Status

| Status | Description |
|--------|-------------|
| `active` | Card can be used for transactions |
| `frozen` | Temporarily blocked |
| `closed` | Permanently deactivated |

## Secure Checkout

Proxy supports two checkout modes:

| Mode | Best For | Endpoint |
|------|----------|----------|
| Browser fill | Standard web checkout forms | `POST /checkout/fill` |
| Server-side execute | API-backed providers and iframe-heavy flows | `POST /checkout/execute` |

<Note>
  `POST /cards/{cardId}/details` is deprecated. Prefer checkout endpoints so card data is not exposed to model context.
</Note>

## Card Actions

### Freeze a Card

```bash
curl -X POST https://api.useproxy.ai/v1/cards/card_xxx/freeze \
  -H "Authorization: Bearer your_api_key"
```

### Unfreeze a Card

```bash
curl -X POST https://api.useproxy.ai/v1/cards/card_xxx/unfreeze \
  -H "Authorization: Bearer your_api_key"
```

### Close a Card

```bash
curl -X DELETE https://api.useproxy.ai/v1/cards/card_xxx \
  -H "Authorization: Bearer your_api_key"
```

### List Card Transactions

```bash
curl "https://api.useproxy.ai/v1/cards/card_xxx/transactions?limit=20" \
  -H "Authorization: Bearer your_api_key"
```

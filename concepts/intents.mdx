# Intents

An **Intent** is a pre-transaction declaration of what an agent plans to purchase.

## Why Intents?

1. Approval workflows for high-risk purchases.
2. Merchant and amount policy checks before execution.
3. Audit trail linking purchases to business purpose.

## Create an Intent

```bash
curl -X POST https://api.useproxy.ai/v1/intents \
  -H "Authorization: Bearer your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "cardId": "card_xxx",
    "purpose": "Purchase office supplies",
    "expectedAmount": 5000,
    "expectedMerchant": "Amazon"
  }'
```

## Intent Lifecycle

| Status | Description |
|--------|-------------|
| `pending_approval` | Awaiting human approval |
| `card_issued` | Card is available for checkout |
| `approved` | Approved for execution |
| `completed` | Checkout executed successfully |
| `rejected` | Rejected by policy/human |
| `expired` | Intent expired before use |

## Execute After Intent

- Browser form: `POST /checkout/fill`
- Server-side adapter: `POST /checkout/execute`

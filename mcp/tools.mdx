## Checkout

### `proxy.checkout.fill`

Generate a browser script that fills checkout fields without exposing PAN/CVV to model context.

Inputs:
- `intentId`
- `cardId`
- `pageUrl` (optional)
- `dryRun` (optional)
- `fieldHints` (optional)

### `proxy.checkout.execute`

Execute a server-side adapter checkout flow without exposing raw card data.

Inputs:
- `intentId`
- `cardId`
- `merchantId`
- `idempotencyKey`
- `merchantParams` (optional)

# Tools Reference

The Proxy API MCP server provides 12 tools organized by function.

## Agent Tools

These tools are available with both API keys and agent tokens.

### proxy_status

Get user verification status, balance, and spending eligibility.

```json
{
  "userId": "user_xxx"
}
```

**Response:**

```json
{
  "userId": "user_xxx",
  "verificationStatus": "approved",
  "balance": 50000,
  "currency": "USD",
  "canSpend": true
}
```

---

### proxy_funding

Manage account funding. Check balance and get deposit instructions.

#### Actions

| Action | Description | Required Parameters |
|--------|-------------|---------------------|
| `balance` | Check available funds | `userId` |
| `crypto` | Get USDC deposit address | `userId` |
| `ach` | Bank transfer (coming soon) | `userId` |
| `wire` | Wire transfer (coming soon) | `userId` |

#### Check balance

```json
{
  "action": "balance",
  "userId": "user_xxx"
}
```

**Response:**

```json
{
  "available": 50000,
  "currency": "USD"
}
```

#### Get crypto deposit address

```json
{
  "action": "crypto",
  "userId": "user_xxx",
  "chain": "base"
}
```

**Optional:** `chain` - `"base"` (default), `"ethereum"`, or `"solana"`

**Response:**

```json
{
  "method": "crypto",
  "address": "0x1234...abcd",
  "chain": "base",
  "asset": "USDC",
  "message": "Send USDC to this address on base to fund the account."
}
```

#### ACH / Wire (Coming Soon)

```json
{
  "action": "ach",
  "userId": "user_xxx"
}
```

**Response:**

```json
{
  "method": "ach",
  "status": "coming_soon",
  "message": "ACH bank transfers are not yet available. Use crypto deposits for now."
}
```

### proxy_card

Manage virtual cards. Use the `action` parameter to specify the operation.

#### Actions

| Action | Description | Required Parameters |
|--------|-------------|---------------------|
| `create` | Create a new card | `purpose` |
| `list` | List all cards | - |
| `details` | Get PAN/CVV/expiry | `cardId`, `summary` |
| `freeze` | Freeze a card | `cardId` |
| `unfreeze` | Unfreeze a card | `cardId` |
| `close` | Close a card | `cardId` |
| `update` | Update card limits | `cardId` |

#### Create a card

```json
{
  "action": "create",
  "purpose": "Buy office supplies on Amazon",
  "type": "single",
  "maxAmount": 5000
}
```

**Optional parameters:**
- `type`: `"single"` (default) or `"multi"`
- `maxAmount`: Maximum spend in cents (single-use)
- `limitPerAuth`: Per-transaction limit in cents (multi-use)
- `limitPerDay`: Daily limit in cents (multi-use)
- `limitPerMonth`: Monthly limit in cents (multi-use)
- `ttlMinutes`: Auto-expire after N minutes
- `intentTolerance`: Max % deviation from declared amount (0.0-1.0)
- `policyId`: Apply a policy template

#### Get card details

```json
{
  "action": "details",
  "cardId": "card_xxx",
  "summary": "Purchasing office supplies",
  "expectedAmount": 4500
}
```

**Response:**

```json
{
  "pan": "4111111111111234",
  "cvv": "123",
  "expiry": "12/27",
  "billingAddress": {
    "line1": "123 Main St",
    "city": "San Francisco",
    "state": "CA",
    "postalCode": "94102",
    "country": "US"
  }
}
```

#### List cards

```json
{
  "action": "list",
  "status": "active"
}
```

#### Freeze/Unfreeze/Close

```json
{
  "action": "freeze",
  "cardId": "card_xxx",
  "reason": "Suspicious activity"
}
```

### proxy_onboarding

Get KYC verification link for user identity verification.

```json
{
  "userId": "user_xxx"
}
```

**Response:**

```json
{
  "verificationUrl": "https://persona.com/verify/...",
  "message": "Share this link with the user to complete identity verification."
}
```

<Note>For deposit addresses and funding, use the `proxy_funding` tool.</Note>

## Admin Tools

These tools are only available with API keys (not agent tokens).

### proxy_users

Manage users.

#### Create user

```json
{
  "action": "create",
  "externalId": "your-user-id",
  "firstName": "John",
  "lastName": "Doe",
  "email": "john@example.com"
}
```

**Optional:** `dateOfBirth`, `addressLine1`, `city`, `state`, `postalCode`, `country`

#### Get user

```json
{
  "action": "get",
  "userId": "user_xxx"
}
```

#### List users

```json
{
  "action": "list",
  "limit": 20
}
```

### proxy_risk

Manage risk detection settings.

#### Get current config

```json
{
  "action": "get"
}
```

#### Apply preset

```json
{
  "action": "preset",
  "preset": "moderate"
}
```

Available presets: `permissive`, `moderate`, `strict`, `paranoid`

#### Update settings

```json
{
  "action": "update",
  "velocityEnabled": true,
  "velocityMaxPerHour": 20,
  "velocityAction": "freeze_card",
  "dryRun": false
}
```

### proxy_webhooks

Manage webhook endpoints.

#### Create webhook

```json
{
  "action": "create",
  "url": "https://your-app.com/webhooks",
  "events": ["transaction.completed", "card.frozen"]
}
```

#### List webhooks

```json
{
  "action": "list"
}
```

#### Delete webhook

```json
{
  "action": "delete",
  "webhookId": "wh_xxx"
}
```

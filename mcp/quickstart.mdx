# MCP Quickstart

## Server URL

`https://mcp.useproxy.ai/api/mcp`

## Authentication

- Human workflows: OAuth via your MCP client.
- Agent workflows: Proxy agent token (`prxy_sk_...`).

## Verify Connection

Ask your client to list tools, then run:

1. `proxy.user.get`
2. `proxy.intents.create`
3. `proxy.intents.get`
4. `proxy.checkout.fill` or `proxy.checkout.execute`

## Example Flow

```text
Create intent -> verify intent/card -> run secure checkout -> confirm result
```

## Troubleshooting

- If browser fill fails due iframe/CSP, use `proxy.checkout.execute`.
- If intent is not ready, ensure status is `card_issued` before checkout.

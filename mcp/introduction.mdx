# Model Context Protocol (MCP)

The Proxy MCP server lets AI clients call Proxy tools directly.

## Endpoint

`https://mcp.useproxy.ai/api/mcp`

## What Changed

Proxy now supports secure checkout tools so agents do not need raw PAN/CVV in model context.

## Key Tool Categories

| Category | Examples |
|----------|----------|
| Identity | `proxy.user.get`, `proxy.kyc.status`, `proxy.kyc.link` |
| Intents | `proxy.intents.create`, `proxy.intents.get`, `proxy.intents.approve` |
| Checkout | `proxy.checkout.fill`, `proxy.checkout.execute` |
| Transactions | `proxy.transactions.get`, `proxy.transactions.list_for_card` |
| Funding/Balance | `proxy.balance.get`, `proxy.funding.get` |

## Recommended Spend Flow

1. `proxy.intents.create`
2. `proxy.intents.get`
3. `proxy.checkout.fill` (browser) or `proxy.checkout.execute` (server-side)

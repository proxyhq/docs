# Examples

Real-world examples showing how AI agents use Proxy MCP tools.

## Make a Purchase

The most common flow: check if user can spend, create a card, get details, complete checkout.

```
User: "Buy me a $30 book on Amazon"

Agent:
1. proxy_status({ userId: "user_xxx" })
   → { canSpend: true, balance: 5000, verificationStatus: "approved" }

2. proxy_card({
     action: "create",
     purpose: "Buy book on Amazon",
     type: "single",
     maxAmount: 3500
   })
   → { cardId: "card_abc", lastFour: "4242", status: "active" }

3. proxy_card({
     action: "details",
     cardId: "card_abc",
     summary: "Purchasing book on Amazon"
   })
   → { pan: "4111111111114242", cvv: "123", expiry: "12/27", billingAddress: {...} }

4. [Agent navigates to Amazon, adds book to cart, enters card details at checkout]

5. proxy_transactions({ cardId: "card_abc" })
   → { transactions: [{ amount: 2999, merchantName: "AMAZON.COM", status: "completed" }] }

Agent: "Done! I bought the book for $29.99. Your card has been automatically closed."
```

## User Onboarding

Help a new user get verified and funded:

```
User: "I want to start using the shopping agent"

Agent:
1. proxy_status({ userId: "user_xxx" })
   → { verificationStatus: "notStarted", balance: 0, canSpend: false }

Agent: "You need to complete identity verification first."

2. proxy_onboarding({ userId: "user_xxx" })
   → { verificationUrl: "https://persona.com/verify/abc123" }

Agent: "Please complete verification here: [link]"

[User completes KYC]

3. proxy_status({ userId: "user_xxx" })
   → { verificationStatus: "approved", balance: 0, canSpend: false }

Agent: "Great, you're verified! Now you need to add funds."

4. proxy_funding({
     action: "crypto",
     userId: "user_xxx",
     chain: "base"
   })
   → { method: "crypto", address: "0x1234...", chain: "base", asset: "USDC" }

Agent: "Send USDC to this address on Base: 0x1234..."

[User sends USDC]

5. proxy_funding({ action: "balance", userId: "user_xxx" })
   → { available: 10000, currency: "USD" }

Agent: "You're all set! You have $100 available to spend."
```

## Multi-Use Card with Intents

Create a reusable card that requires intent declaration before each purchase:

```
User: "Create a card I can use for multiple small purchases this week"

Agent:
1. proxy_card({
     action: "create",
     purpose: "Weekly small purchases",
     type: "multi",
     limitPerDay: 5000
   })
   → { cardId: "card_xyz", lastFour: "8888", type: "multi" }

Agent: "Created a multi-use card with $50/day limit. I'll declare intent before each purchase."

[Later...]

User: "Buy me a coffee"

Agent:
2. proxy_intent({
     action: "declare",
     cardId: "card_xyz",
     summary: "Buy coffee at Starbucks",
     expectedAmount: 650
   })
   → { intentId: "int_123", status: "pending" }

3. proxy_card({
     action: "details",
     cardId: "card_xyz",
     summary: "Coffee at Starbucks"
   })
   → { pan: "...", cvv: "...", expiry: "..." }

[Agent completes purchase]
```

## Admin: Register an Agent

Set up a new AI agent for a user:

```
Admin workflow:

1. proxy_users({
     action: "create",
     externalId: "customer-123",
     firstName: "Jane",
     lastName: "Smith",
     email: "jane@company.com"
   })
   → { userId: "user_abc" }

2. proxy_agents({
     action: "register",
     externalId: "d290f1ee-6c54-4b01-90e6-d701748f0851",
     userId: "user_abc",
     name: "Shopping Assistant",
     description: "Helps Jane buy products online"
   })
   → { agentId: "agent_xyz", status: "active" }

3. [Create agent token via API for the agent to use at runtime]
```

## Admin: Configure Risk Detection

Set up anomaly detection for your organization:

```
1. proxy_risk({ action: "get" })
   → { duplicateDetection: {...}, velocityLimit: {...}, ... }

2. proxy_risk({
     action: "preset",
     preset: "moderate"
   })
   → { message: "Applied 'moderate' preset", config: {...} }

3. proxy_risk({
     action: "update",
     velocityMaxPerHour: 30,
     dryRun: true
   })
   → { message: "Config updated", config: {...} }

[Monitor webhooks in dry-run mode, then disable dryRun when ready]
```

## Error Handling

The MCP server returns errors as JSON in the response:

```json
{
  "error": "cardId is required"
}
```

Common errors:

| Error | Cause | Solution |
|-------|-------|----------|
| `Agent ID not configured` | Missing PROXY_AGENT_ID env | Set agent ID with agent token |
| `cardId is required` | Missing required parameter | Include the parameter |
| `summary is required for attestation` | Getting details without summary | Provide what you're purchasing |
| `User not verified` | User hasn't completed KYC | Use `proxy_onboarding` first |
| `Insufficient balance` | Not enough funds | Use `proxy_funding` to get deposit info |

# API Reference

The Proxy API enables you to manage customers, agents, cards, intents, and secure checkout flows.

## Base URL

```
https://api.useproxy.ai/v1
```

## Secure Checkout Endpoints

- `POST /checkout/fill` - generate browser fill script (agent-oriented)
- `POST /checkout/execute` - server-side adapter execution
- `POST /checkout/fill-data` - one-time token redemption for fill scripts
- `POST /checkout/fill-result` - fill script result telemetry

## Legacy Endpoint

`POST /cards/{cardId}/details` remains for break-glass use only and is deprecated.

## Request Format

All requests use JSON bodies and require the `Content-Type: application/json` header.

## Errors

Errors return standard HTTP codes with a machine-readable code and message.

# Agents

Agents represent autonomous actors (AI systems, automation scripts, etc.) that spend on behalf of customers. Each agent can have its own spending limits and policies that override customer defaults.

## The Agent Object

```json
{
  "id": "agt_abc123",
  "customerId": "cus_xyz789",
  "externalId": "my-agent-001",
  "status": "active",
  "name": "Shopping Assistant",
  "limits": {
    "amount": 100000,
    "currency": "usd",
    "interval": "daily"
  },
  "policy": {
    "requireIntent": true,
    "autoApproveBelow": 5000
  },
  "metadata": {},
  "createdAt": "2024-01-15T10:30:00.000Z"
}
```

### Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique identifier for the agent (prefixed with `agt_`) |
| `customerId` | string | ID of the customer this agent belongs to |
| `externalId` | string | Your unique identifier for this agent |
| `status` | string | Agent status: `active`, `paused`, or `disabled` |
| `name` | string | Display name for the agent |
| `limits.amount` | number | Spending limit amount in minor units (cents) |
| `limits.currency` | string | Currency code (e.g., `usd`) |
| `limits.interval` | string | Limit interval: `daily`, `weekly`, `monthly`, or `all_time` |
| `policy` | object | Spending policy overrides |
| `metadata` | object | Arbitrary key-value pairs |
| `createdAt` | string | ISO 8601 timestamp of creation |

## Create an Agent

<div className="api-method-badge">POST</div>

```
POST /v1/agents
```

Creates a new agent for a customer. If an agent with the same `externalId` already exists for the customer, the existing agent is returned.

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `customerId` | string | Yes | ID of the parent customer |
| `externalId` | string | Yes | Your unique identifier for this agent |
| `name` | string | No | Display name (defaults to externalId) |
| `status` | string | No | Initial status: `active` (default), `paused`, or `disabled` |
| `limits.amount` | number | No | Spending limit in minor units |
| `limits.currency` | string | No | Currency code (default: `usd`) |
| `limits.interval` | string | No | Limit interval |
| `policy` | object | No | Policy overrides |
| `metadata` | object | No | Custom key-value pairs |

### Example

<CodeGroup>
```bash cURL
curl -X POST https://api.useproxy.ai/v1/agents \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": "cus_xyz789",
    "externalId": "shopping-assistant-001",
    "name": "Shopping Assistant",
    "limits": {
      "amount": 100000,
      "currency": "usd",
      "interval": "daily"
    },
    "policy": {
      "requireIntent": true,
      "autoApproveBelow": 5000
    }
  }'
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/agents', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    customerId: 'cus_xyz789',
    externalId: 'shopping-assistant-001',
    name: 'Shopping Assistant',
    limits: {
      amount: 100000,
      currency: 'usd',
      interval: 'daily'
    },
    policy: {
      requireIntent: true,
      autoApproveBelow: 5000
    }
  })
});

const agent = await response.json();
```

```python Python

response = requests.post(
    'https://api.useproxy.ai/v1/agents',
    headers={
        'Authorization': 'Bearer sk_live_xxxxx',
        'Content-Type': 'application/json'
    },
    json={
        'customerId': 'cus_xyz789',
        'externalId': 'shopping-assistant-001',
        'name': 'Shopping Assistant',
        'limits': {
            'amount': 100000,
            'currency': 'usd',
            'interval': 'daily'
        },
        'policy': {
            'requireIntent': True,
            'autoApproveBelow': 5000
        }
    }
)

agent = response.json()
```
</CodeGroup>

## List Agents

<div className="api-method-badge get">GET</div>

```
GET /v1/agents
```

Returns a paginated list of agents, optionally filtered by customer.

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `customerId` | string | Filter by customer ID |
| `limit` | number | Maximum number of results (default: 50) |
| `cursor` | string | Pagination cursor from previous response |

### Example

<CodeGroup>
```bash cURL
curl "https://api.useproxy.ai/v1/agents?customerId=cus_xyz789&limit=10" \
  -H "Authorization: Bearer sk_live_xxxxx"
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/agents?customerId=cus_xyz789&limit=10', {
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx'
  }
});

const { data, nextCursor } = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.useproxy.ai/v1/agents',
    headers={'Authorization': 'Bearer sk_live_xxxxx'},

result = response.json()
```

## Update an Agent

<div className="api-method-badge patch">PATCH</div>

```
PATCH /v1/agents/:id
```

Updates an existing agent.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | The agent ID |

### Request Body

| Parameter | Type | Description |
|-----------|------|-------------|
| `name` | string | New display name |
| `status` | string | New status: `active`, `paused`, or `disabled` |
| `limits.amount` | number | New spending limit |
| `limits.currency` | string | Currency code |
| `limits.interval` | string | Limit interval |
| `policy` | object | Updated policy |
| `metadata` | object | Updated metadata |

### Example

<CodeGroup>
```bash cURL
curl -X PATCH https://api.useproxy.ai/v1/agents/agt_abc123 \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "paused",
    "limits": {
      "amount": 50000,
      "currency": "usd",
      "interval": "daily"
    }
  }'
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/agents/agt_abc123', {
```

## Agent Status Values

| Status | Description |
|--------|-------------|
| `active` | Agent can create intents and access cards |
| `paused` | Agent is temporarily suspended but can be reactivated |
| `disabled` | Agent is permanently disabled (deleted) |

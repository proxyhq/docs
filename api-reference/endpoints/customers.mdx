# Customers

Customers represent end users of your platform who can have cards issued on their behalf. A customer can be either a `consumer` (individual) or `corporate` (business entity).

## The Customer Object

```json
{
  "id": "cus_abc123",
  "type": "consumer",
  "status": "active",
  "email": "alice@example.com",
  "phone": "+14155551234",
  "name": {
    "first": "Alice",
    "last": "Smith"
  },
  "policy": {
    "requireIntent": true,
    "limits": {
      "perDay": 500000
    }
  },
  "metadata": {},
  "createdAt": "2024-01-15T10:30:00.000Z"
}
```

### Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique identifier for the customer (prefixed with `cus_`) |
| `type` | string | Customer type: `consumer` or `corporate` |
| `status` | string | Customer status: `pending`, `active`, or `deleted` |
| `email` | string | Customer's email address |
| `phone` | string | Customer's phone number with country code |
| `name.first` | string | Customer's first name |
| `name.last` | string | Customer's last name |
| `policy` | object | Default spending policy for this customer |
| `metadata` | object | Arbitrary key-value pairs for your use |
| `createdAt` | string | ISO 8601 timestamp of creation |

## Create a Customer

<div className="api-method-badge">POST</div>

```
POST /v1/customers
```

Creates a new customer.

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `type` | string | No | `consumer` (default) or `corporate` |
| `email` | string | No | Customer's email address |
| `phone` | string | No | Customer's phone number |
| `name.first` | string | No | First name |
| `name.last` | string | No | Last name |
| `policy` | object | No | Default spending policy |
| `metadata` | object | No | Custom key-value pairs |

### Example

<CodeGroup>
```bash cURL
curl -X POST https://api.useproxy.ai/v1/customers \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "consumer",
    "email": "alice@example.com",
    "name": {
      "first": "Alice",
      "last": "Smith"
    },
    "policy": {
      "requireIntent": true,
      "limits": {
        "perDay": 500000
      }
    }
  }'
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/customers', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    type: 'consumer',
    email: 'alice@example.com',
    name: {
      first: 'Alice',
      last: 'Smith'
    },
    policy: {
      requireIntent: true,
      limits: {
        perDay: 500000
      }
    }
  })
});

const customer = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.useproxy.ai/v1/customers',
    headers={
        'Authorization': 'Bearer sk_live_xxxxx',
        'Content-Type': 'application/json'
    },
    json={
        'type': 'consumer',
        'email': 'alice@example.com',
        'name': {
            'first': 'Alice',
            'last': 'Smith'
        },
        'policy': {
            'requireIntent': True,
            'limits': {
                'perDay': 500000
            }
        }
    }
)

customer = response.json()
```
</CodeGroup>

### Response

```json

  "id": "cus_abc123",
  "type": "consumer",
  "status": "pending",

  "phone": null,
```

## List Customers

<div className="api-method-badge get">GET</div>

```
GET /v1/customers
```

Returns a paginated list of customers.

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `limit` | number | Maximum number of results (default: 50) |
| `cursor` | string | Pagination cursor from previous response |

### Example

<CodeGroup>
```bash cURL
curl "https://api.useproxy.ai/v1/customers?limit=10" \
  -H "Authorization: Bearer sk_live_xxxxx"
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/customers?limit=10', {
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx'
  }
});

const { data, nextCursor } = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.useproxy.ai/v1/customers',
    headers={'Authorization': 'Bearer sk_live_xxxxx'},
    params={'limit': 10}
)

result = response.json()
customers = result['data']
```
</CodeGroup>

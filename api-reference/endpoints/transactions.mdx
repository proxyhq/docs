# Transactions

Transactions represent card spending events. All transactions are synced from the card network and include details about the merchant, amount, and status.

## The Transaction Object

```json
{
  "id": "txn_abc123",
  "customerId": "cus_xyz789",
  "cardId": "card_def456",
  "agentId": "agt_ghi012",
  "type": "spend",
  "status": "approved",
  "amount": 2500,
  "currency": "usd",
  "merchant": {
    "name": "AMAZON.COM",
    "mcc": "5942",
    "city": "Seattle",
    "state": "WA",
    "country": "US"
  },
  "memo": "Office supplies Q1",
  "createdAt": "2024-01-15T14:30:00.000Z",
  "updatedAt": "2024-01-15T14:30:00.000Z"
}
```

### Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique identifier (prefixed with `txn_`) |
| `customerId` | string | ID of the customer |
| `cardId` | string | ID of the card used |
| `agentId` | string | ID of the agent (if applicable) |
| `type` | string | Transaction type: `spend`, `refund`, `adjustment` |
| `status` | string | Transaction status |
| `amount` | number | Transaction amount in minor units (cents) |
| `currency` | string | Currency code |
| `merchant` | object | Merchant details |
| `merchant.name` | string | Merchant name |
| `merchant.mcc` | string | Merchant category code |
| `merchant.city` | string | Merchant city |
| `merchant.state` | string | Merchant state |
| `merchant.country` | string | Merchant country |
| `memo` | string | Custom memo/note |
| `createdAt` | string | ISO 8601 creation timestamp |
| `updatedAt` | string | ISO 8601 last update timestamp |

### Status Values

| Status | Description |
|--------|-------------|
| `pending` | Authorization pending |
| `approved` | Transaction approved |
| `declined` | Transaction declined |
| `settled` | Transaction settled |
| `reversed` | Transaction reversed/refunded |

## Retrieve a Transaction

<div className="api-method-badge get">GET</div>

```
GET /v1/transactions/:id
```

Retrieves a transaction by ID.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | The transaction ID (e.g., `txn_abc123`) |

### Example

<CodeGroup>
```bash cURL
curl https://api.useproxy.ai/v1/transactions/txn_abc123 \
  -H "Authorization: Bearer sk_live_xxxxx"
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/transactions/txn_abc123', {
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx'
  }
});

const transaction = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.useproxy.ai/v1/transactions/txn_abc123',
    headers={'Authorization': 'Bearer sk_live_xxxxx'}
)

transaction = response.json()
```
</CodeGroup>

### Response

## List Transactions

<div className="api-method-badge get">GET</div>

```
GET /v1/transactions
```

Returns a paginated list of transactions.

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `customerId` | string | Filter by customer ID |
| `cardId` | string | Filter by card ID |
| `agentId` | string | Filter by agent ID |
| `limit` | number | Maximum results (default: 50) |
| `cursor` | string | Pagination cursor |

### Example

<CodeGroup>
```bash cURL
curl "https://api.useproxy.ai/v1/transactions?customerId=cus_xyz789&limit=20" \
  -H "Authorization: Bearer sk_live_xxxxx"
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/transactions?customerId=cus_xyz789&limit=20', {
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx'
  }
});

const { data, nextCursor } = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.useproxy.ai/v1/transactions',
    headers={'Authorization': 'Bearer sk_live_xxxxx'},
    params={
        'customerId': 'cus_xyz789',
        'limit': 20
    }
)

result = response.json()
```

## Update Transaction Memo

<div className="api-method-badge patch">PATCH</div>

```
PATCH /v1/transactions/:id
```

Updates the memo/note on a transaction.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | The transaction ID |

### Request Body

| Parameter | Type | Description |
|-----------|------|-------------|
| `memo` | string | Custom note for this transaction |

### Example

<CodeGroup>
```bash cURL
curl -X PATCH https://api.useproxy.ai/v1/transactions/txn_abc123 \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "memo": "Office supplies for Q1 2024"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/transactions/txn_abc123', {
  method: 'PATCH',
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    memo: 'Office supplies for Q1 2024'
  })
});

const transaction = await response.json();
```

```python Python
import requests

response = requests.patch(
    'https://api.useproxy.ai/v1/transactions/txn_abc123',
    headers={
        'Authorization': 'Bearer sk_live_xxxxx',
        'Content-Type': 'application/json'
    },
    json={
        'memo': 'Office supplies for Q1 2024'
    }
)

transaction = response.json()
```
</CodeGroup>

## Evaluate Spend Policy

<div className="api-method-badge">POST</div>

```
POST /v1/spend/evaluate
```

Evaluates a hypothetical transaction against the current spending policies without actually creating a transaction. Useful for pre-flight checks.

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `amount` | number | Yes | Amount to evaluate in minor units |
| `customerId` | string | No | Customer ID |
| `agentId` | string | No | Agent ID |
| `cardId` | string | No | Card ID |
| `currency` | string | No | Currency code |
| `merchant.mcc` | string | No | Merchant category code |
| `merchant.name` | string | No | Merchant name |

### Example

<CodeGroup>
```bash cURL
curl -X POST https://api.useproxy.ai/v1/spend/evaluate \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 15000,
    "cardId": "card_def456",
    "merchant": {
      "mcc": "5812",
      "name": "Restaurant XYZ"
    }
  }'
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/spend/evaluate', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount: 15000,
    cardId: 'card_def456',
    merchant: {
      mcc: '5812',
      name: 'Restaurant XYZ'
    }
  })
});

const evaluation = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.useproxy.ai/v1/spend/evaluate',
    headers={
        'Authorization': 'Bearer sk_live_xxxxx',
        'Content-Type': 'application/json'
    },
    json={
        'amount': 15000,
        'cardId': 'card_def456',
        'merchant': {
            'mcc': '5812',
            'name': 'Restaurant XYZ'
        }
    }
)

evaluation = response.json()
```
</CodeGroup>

### Decline Reason Codes

| Code | Description |
|------|-------------|
| `customer_not_found` | Customer does not exist |
| `agent_disabled` | Agent is not active |
| `card_not_active` | Card is locked, canceled, or inactive |
| `blocked_mcc` | MCC is globally blocked (high-risk) |
| `blocked_mcc_policy` | MCC is blocked by policy |
| `mcc_not_allowed` | MCC not in allowed list |
| `merchant_not_allowed` | Merchant not in allowed list |
| `merchant_locked` | Card is locked to a different merchant |
| `single_use_consumed` | Single-use card already used |
| `card_expired` | Card has expired |
| `cooldown_active` | Cooldown period not elapsed |
| `account_credit_limit_exceeded` | Exceeds available balance |
| `agent_spending_limit_exceeded` | Exceeds agent limit |
| `card_spending_limit_exceeded` | Exceeds card limit |
| `limit_per_auth_exceeded` | Exceeds per-authorization limit |
| `limit_per_day_exceeded` | Exceeds daily limit |
| `limit_per_month_exceeded` | Exceeds monthly limit |

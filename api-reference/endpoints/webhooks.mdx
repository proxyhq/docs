# Webhooks

Webhooks enable you to receive real-time notifications when events occur in your Proxy account. Configure webhook subscriptions to receive HTTP POST requests to your endpoint.

## The Webhook Subscription Object

```json
{
  "id": "whk_abc123",
  "url": "https://your-server.com/webhooks/proxy",
  "events": ["card.created", "transaction.approved"],
  "enabled": true,
  "secret": "whsec_xxxxx",
  "createdAt": "2024-01-15T10:00:00.000Z",
  "updatedAt": "2024-01-15T10:00:00.000Z"
}
```

### Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique identifier (prefixed with `whk_`) |
| `url` | string | HTTPS endpoint to receive webhook events |
| `events` | array | List of event types to subscribe to (empty = all events) |
| `enabled` | boolean | Whether the subscription is active |
| `secret` | string | Signing secret for verifying webhook signatures |
| `createdAt` | string | ISO 8601 creation timestamp |
| `updatedAt` | string | ISO 8601 last update timestamp |

## Create a Webhook Subscription

<div className="api-method-badge">POST</div>

```
POST /v1/webhooks
```

Creates a new webhook subscription.

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `url` | string | Yes | HTTPS endpoint URL |
| `events` | array | No | Event types to subscribe to (empty = all) |
| `enabled` | boolean | No | Whether subscription is active (default: true) |
| `secret` | string | No | Custom signing secret (auto-generated if not provided) |
| `metadata` | object | No | Custom key-value pairs |

### Example

<CodeGroup>
```bash cURL
curl -X POST https://api.useproxy.ai/v1/webhooks \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://your-server.com/webhooks/proxy",
    "events": [
      "card.created",
      "card.updated",
      "transaction.approved",
      "transaction.declined",
      "intent.pending_approval"
    ]
  }'
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/webhooks', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    url: 'https://your-server.com/webhooks/proxy',
    events: [
      'card.created',
      'card.updated',
      'transaction.approved',
      'transaction.declined',
      'intent.pending_approval'
    ]
  })
});

const webhook = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.useproxy.ai/v1/webhooks',
    headers={
        'Authorization': 'Bearer sk_live_xxxxx',
        'Content-Type': 'application/json'
    },
    json={
        'url': 'https://your-server.com/webhooks/proxy',
        'events': [
            'card.created',
            'card.updated',
            'transaction.approved',
            'transaction.declined',
            'intent.pending_approval'
        ]
    }
)

webhook = response.json()
```
</CodeGroup>

## Webhook Event Format

When an event occurs, Proxy sends a POST request to your endpoint:

```json
{
  "id": "evt_abc123",
  "type": "transaction.approved",
  "created": "2024-01-15T14:30:00.000Z",
  "data": {
    "id": "txn_xyz789",
    "customerId": "cus_abc123",
    "cardId": "card_def456",
    "type": "spend",
    "status": "approved",
    "amount": 2500,
    "currency": "usd",
    "merchant": {
      "name": "AMAZON.COM",
      "mcc": "5942"
    }
  }
}
```

### Signature Verification

Each webhook request includes a signature header for verification:

```
Proxy-Signature: t=1705329000,v1=abc123...
```

Verify the signature using your webhook secret:

<CodeGroup>
```javascript JavaScript
const crypto = require('crypto');

function verifyWebhookSignature(payload, signature, secret) {
  const [timestamp, hash] = signature.split(',').reduce((acc, part) => {
    const [key, value] = part.split('=');
    if (key === 't') acc[0] = value;
    if (key === 'v1') acc[1] = value;
    return acc;
  }, [null, null]);

  const signedPayload = `${timestamp}.${payload}`;
  const expectedHash = crypto
    .createHmac('sha256', secret)
    .update(signedPayload)
    .digest('hex');

  return crypto.timingSafeEqual(
    Buffer.from(hash),
    Buffer.from(expectedHash)
  );
}
```

```python Python
import hmac
import hashlib

def verify_webhook_signature(payload, signature, secret):
    parts = dict(part.split('=') for part in signature.split(','))
    timestamp = parts.get('t')
    received_hash = parts.get('v1')

    signed_payload = f"{timestamp}.{payload}"
    expected_hash = hmac.new(
        secret.encode(),
        signed_payload.encode(),
        hashlib.sha256
    ).hexdigest()

    return hmac.compare_digest(received_hash, expected_hash)
```
</CodeGroup>

## Available Event Types

### Customer Events
| Event | Description |
|-------|-------------|
| `customer.created` | Customer created |
| `customer.updated` | Customer updated |
| `customer.deleted` | Customer deleted |

| Event | Description |
|-------|-------------|

| `agent.updated` | Agent updated |

|-------|-------------|

| Event | Description |

## Retry Policy

If your endpoint returns a non-2xx response or times out, Proxy will retry the delivery:

| Attempt | Delay |
|---------|-------|
| 1 | Immediate |
| 2 | 1 minute |
| 3 | 5 minutes |
| 4 | 30 minutes |
| 5 | 2 hours |
| 6 | 12 hours |

After 6 failed attempts, the delivery is marked as failed.

---

## Best Practices

1. **Respond quickly** - Return a 200 response as soon as you receive the webhook, then process asynchronously
2. **Verify signatures** - Always verify the `Proxy-Signature` header
3. **Handle duplicates** - Webhooks may be delivered more than once; use idempotency
4. **Use HTTPS** - Only HTTPS endpoints are supported
5. **Monitor failures** - Check your endpoint health and Proxy dashboard for failed deliveries

# Cards

Cards are virtual spending instruments issued to customers. Cards can be assigned to agents and configured with spending policies, limits, and merchant restrictions.

## The Card Object

```json
{
  "id": "card_abc123",
  "customerId": "cus_xyz789",
  "agentId": "agt_def456",
  "type": "virtual",
  "usage": "multi",
  "status": "active",
  "last4": "4242",
  "expMonth": 12,
  "expYear": 2027,
  "limits": {
    "amount": 50000,
    "currency": "usd",
    "interval": "daily"
  },
  "merchantLock": null,
  "expiresAt": null,
  "lastSpendAt": "2024-01-15T14:30:00.000Z",
  "firstSpendAt": "2024-01-10T09:00:00.000Z",
  "singleUseConsumedAt": null,
  "policy": {
    "requireIntent": true
  },
  "createdAt": "2024-01-10T08:00:00.000Z"
}
```

### Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `id` | string | Unique identifier (prefixed with `card_`) |
| `customerId` | string | ID of the owning customer |
| `agentId` | string | ID of the assigned agent (if any) |
| `type` | string | Card type: `virtual` |
| `usage` | string | Usage mode: `single` or `multi` |
| `status` | string | Card status: `active`, `locked`, `canceled` |
| `last4` | string | Last 4 digits of card number |
| `expMonth` | number | Expiration month (1-12) |
| `expYear` | number | Expiration year |
| `limits.amount` | number | Spending limit in minor units |
| `limits.currency` | string | Currency code |
| `limits.interval` | string | Limit interval |
| `merchantLock` | string | Locked to a specific merchant (if set) |
| `expiresAt` | string | Card expiration timestamp (policy-based) |
| `lastSpendAt` | string | Last transaction timestamp |
| `firstSpendAt` | string | First transaction timestamp |
| `singleUseConsumedAt` | string | When single-use card was consumed |
| `policy` | object | Card-level policy overrides |
| `createdAt` | string | ISO 8601 creation timestamp |

## Create a Card

<div className="api-method-badge">POST</div>

```
POST /v1/cards
```

Creates a new virtual card for a customer.

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `customerId` | string | Yes | ID of the customer |
| `agentId` | string | No | ID of the agent to assign |
| `type` | string | No | `virtual` (default) |
| `usage` | string | No | `multi` (default) or `single` |
| `status` | string | No | Initial status (default: `active`) |
| `limits.amount` | number | No | Spending limit in minor units |
| `limits.interval` | string | No | Limit interval |
| `policy` | object | No | Card-level policy |
| `configuration` | object | No | Card configuration options |
| `billing` | object | No | Billing address |

### Example

<CodeGroup>
```bash cURL
curl -X POST https://api.useproxy.ai/v1/cards \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": "cus_xyz789",
    "agentId": "agt_def456",
    "usage": "multi",
    "limits": {
      "amount": 50000,
      "interval": "daily"
    },
    "policy": {
      "requireIntent": true,
      "ttlDays": 30
    }
  }'
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/cards', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    customerId: 'cus_xyz789',
    agentId: 'agt_def456',
    usage: 'multi',
    limits: {
      amount: 50000,
      interval: 'daily'
    },
    policy: {
      requireIntent: true,
      ttlDays: 30
    }
  })
});

const card = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.useproxy.ai/v1/cards',
    headers={
        'Authorization': 'Bearer sk_live_xxxxx',
        'Content-Type': 'application/json'
    },
    json={
        'customerId': 'cus_xyz789',
        'agentId': 'agt_def456',
        'usage': 'multi',
        'limits': {
            'amount': 50000,
            'interval': 'daily'
        },
        'policy': {
            'requireIntent': True,
            'ttlDays': 30
        }
    }
```

## Get Card Details (PAN/CVV)

<div className="api-method-badge">POST</div>

```
POST /v1/cards/:id/details
```

Retrieves sensitive card details (PAN, CVV). This endpoint evaluates access policies before returning credentials.

<Warning>
This endpoint requires proper access control. The request must satisfy the card's policy requirements (intent, attestation, etc.).
</Warning>

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | The card ID |

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `intentId` | string | Conditional | Intent ID if `requireIntent` policy is set |
| `purpose` | string | No | Reason for accessing card details |
| `expectedAmount` | number | No | Expected transaction amount |
| `expectedCurrency` | string | No | Expected currency |
| `merchantText` | string | No | Expected merchant name |

### Example

<CodeGroup>
```bash cURL
curl -X POST https://api.useproxy.ai/v1/cards/card_abc123/details \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "intentId": "int_xyz789",
    "purpose": "Purchase from Amazon",
    "expectedAmount": 2500
  }'
```

```javascript JavaScript
const response = await fetch('https://api.useproxy.ai/v1/cards/card_abc123/details', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_xxxxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    intentId: 'int_xyz789',
    purpose: 'Purchase from Amazon',
    expectedAmount: 2500
  })
});

const details = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.useproxy.ai/v1/cards/card_abc123/details',
    headers={
        'Authorization': 'Bearer sk_live_xxxxx',
        'Content-Type': 'application/json'
    },
    json={
        'intentId': 'int_xyz789',
        'purpose': 'Purchase from Amazon',
        'expectedAmount': 2500
    }
)

details = response.json()
```
</CodeGroup>

### Response (Success)

```json
{
  "accessEventId": "evt_abc123",
  "pan": "4111111111114242",
  "cvv": "123",
  "expirationMonth": 12,
  "expirationYear": 2027,
  "last4": "4242",
  "effectivePolicy": {
    "requireIntent": true
  }
}
```

### Response (Denied)

```json
{
  "error": "access_denied",
  "reasons": [
    {
      "code": "intent_required",
      "message": "An approved intent is required to access this card."
    }
  ]
}
```

## Card Status Values

| Status | Description |
|--------|-------------|
| `active` | Card is active and can be used for transactions |
| `locked` | Card is temporarily frozen |
| `canceled` | Card is permanently closed |
| `inactive` | Card has not been activated yet |

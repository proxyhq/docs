# Webhook Events

This page documents all webhook event types and their payloads.

## Quick Reference

| Category | Events |
|----------|--------|
| **Transactions** | `transaction.authorized`, `transaction.completed`, `transaction.declined`, `transaction.reversed` |
| **Cards** | `card.created`, `card.frozen`, `card.closed`, `card.expired`, `card.merchant_drift` |
| **Agents** | `agent.created`, `agent.suspended`, `agent.activated`, `agent.limit_exceeded`, `agent.limit_approaching` |
| **Users** | `user.created`, `user.updated`, `user.deleted`, `user.balance.updated` |
| **KYC** | `verification.initiated`, `user.application.approved`, `user.application.denied`, `user.application.needs_info` |
| **KYB** | `kyb.submitted`, `kyb.approved`, `kyb.denied`, `kyb.document_uploaded`, `kyb.owner_added`, `kyb.owner_verified` |
| **Deposits** | `deposit.address_ready`, `deposit.received` |
| **Withdrawals** | `withdrawal.submitted`, `withdrawal.confirmed`, `withdrawal.failed` |
| **Attestation** | `credential.accessed`, `spend.attested`, `spend.unattested` |
| **Intents** | `intent.pending_approval`, `intent.approved`, `intent.rejected`, `intent.matched`, `intent.mismatched`, `intent.expired` |
| **Auditors** | `intent.audit_flagged`, `transaction.audit_flagged` |
| **Anomalies** | `anomaly.duplicate`, `anomaly.velocity`, `anomaly.spend_spike`, `anomaly.unattested`, `anomaly.intent_mismatch`, `anomaly.cooldown`, `anomaly.merchant_drift` |
| **Auto-Actions** | `card.auto_frozen`, `agent.auto_suspended` |
| **3DS** | `challenge.requested` |
| **Disputes** | `dispute.created`, `dispute.resolved` |

## Transaction Events

### transaction.authorized

Sent when a transaction is authorized (pending hold placed).

```json
{
  "id": "evt_abc123",
  "type": "transaction.authorized",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "transactionId": "txn_123",
    "cardId": "card_456",
    "agentId": "agent_789",
    "userId": "user_abc",
    "amount": 2500,
    "currency": "USD",
    "merchantName": "DoorDash",
    "merchantCategory": "Restaurants",
    "merchantCategoryCode": "5812",
    "status": "pending",
    "attestationStatus": "attested"
  }
}
```

### transaction.completed

Sent when a transaction settles (funds captured).

```json
{
  "id": "evt_abc123",
  "type": "transaction.completed",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "transactionId": "txn_123",
    "cardId": "card_456",
    "agentId": "agent_789",
    "userId": "user_abc",
    "amount": 2500,
    "authorizedAmount": 2500,
    "currency": "USD",
    "merchantName": "DoorDash",
    "status": "completed",
    "postedAt": 1703606400000
  }
}
```

### transaction.declined

Sent when a transaction is declined.

```json
{
  "id": "evt_abc123",
  "type": "transaction.declined",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "transactionId": "txn_123",
    "cardId": "card_456",
    "agentId": "agent_789",
    "amount": 50000,
    "currency": "USD",
    "merchantName": "Suspicious Merchant",
    "status": "declined",
    "declinedReason": "insufficient_funds"
  }
}
```

**Decline Reasons:**
- `insufficient_funds` - Credit limit exceeded
- `card_frozen` - Card is frozen
- `card_closed` - Card is closed
- `spending_limit_exceeded` - Card or agent limit exceeded
- `blocked_merchant` - Merchant on block list
- `blocked_mcc` - Merchant category blocked
- `fraud_suspected` - Fraud detection triggered

### transaction.reversed

Sent when a refund is processed.

```json
{
  "id": "evt_abc123",
  "type": "transaction.reversed",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "transactionId": "txn_123",
    "cardId": "card_456",
    "originalAmount": 2500,
    "reversedAmount": 2500,
    "currency": "USD",
    "merchantName": "DoorDash",
    "status": "reversed"
  }
}
```

## Card Events

### card.created

Sent when a new card is issued.

```json
{
  "id": "evt_abc123",
  "type": "card.created",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "cardId": "card_456",
    "agentId": "agent_789",
    "userId": "user_abc",
    "type": "single",
    "purpose": "Order dinner on DoorDash",
    "last4": "4242",
    "status": "active"
  }
}
```

### card.frozen

Sent when a card is frozen (manually or by policy).

```json
{
  "id": "evt_abc123",
  "type": "card.frozen",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "cardId": "card_456",
    "agentId": "agent_789",
    "reason": "manual",
    "frozenBy": "api"
  }
}
```

**Freeze Reasons:**
- `manual` - Frozen via API
- `agent_suspended` - Parent agent was suspended
- `spending_limit_exceeded` - Card limit exceeded
- `unattested_spend` - Unattested transaction detected
- `merchant_drift` - Unexpected merchant

### card.closed

Sent when a card is closed.

```json
{
  "id": "evt_abc123",
  "type": "card.closed",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "cardId": "card_456",
    "agentId": "agent_789",
    "reason": "single_use_completed",
    "closedBy": "system"
  }
}
```

**Close Reasons:**
- `manual` - Closed via API
- `single_use_completed` - Single-use card after successful transaction
- `ttl_expired` - Card TTL reached
- `agent_deleted` - Parent agent was deleted

### card.expired

Sent when a card's TTL is reached and the card is auto-frozen or closed.

```json
{
  "id": "evt_abc123",
  "type": "card.expired",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "cardId": "card_456",
    "agentId": "agent_789",
    "userId": "user_abc",
    "action": "close",
    "previousStatus": "active",
    "newStatus": "closed",
    "expiresAt": 1703520000000,
    "ttlMinutes": 60,
    "reason": "ttl_expired"
  }
}
```

### card.merchant_drift

Sent when a transaction occurs at an unexpected merchant (doesn't match `merchantHint`).

```json
{
  "id": "evt_abc123",
  "type": "card.merchant_drift",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "cardId": "card_456",
    "agentId": "agent_789",
    "transactionId": "txn_123",
    "expectedMerchant": "doordash",
    "actualMerchant": "UBER EATS",
    "amount": 2500,
    "action": "allowed"
  }
}
```

**Actions:**
- `allowed` - Transaction proceeded (policy `onDrift: "allow"`)
- `frozen` - Card was frozen (policy `onDrift: "freeze"`)

## KYB Events

KYB (Know Your Business) events are sent during the organization verification process.

### kyb.submitted

Sent when an organization submits their KYB application for review.

```json
{
  "id": "evt_abc123",
  "type": "kyb.submitted",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "organizationId": "org_xyz",
    "legalName": "Acme Corp",
    "businessType": "llc",
    "kybStatus": "under_review",
    "submittedAt": 1703520000000
  }
}
```

### kyb.approved

Sent when an organization's KYB application is approved.

```json
{
  "id": "evt_abc123",
  "type": "kyb.approved",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "organizationId": "org_xyz",
    "legalName": "Acme Corp",
    "kybStatus": "approved",
    "approvedAt": 1703520000000
  }
}
```

<Info>
  Once KYB is approved, the organization can access live API keys and begin processing real transactions.
</Info>

### kyb.denied

Sent when an organization's KYB application is denied.

```json
{
  "id": "evt_abc123",
  "type": "kyb.denied",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "organizationId": "org_xyz",
    "legalName": "Acme Corp",
    "kybStatus": "denied",
    "reason": "Unable to verify business information",
    "deniedAt": 1703520000000
  }
}
```

### kyb.document_uploaded

Sent when a KYB document is uploaded.

```json
{
  "id": "evt_abc123",
  "type": "kyb.document_uploaded",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "organizationId": "org_xyz",
    "documentId": "doc_xyz",
    "documentType": "certificate_of_incorporation",
    "fileName": "certificate.pdf",
    "uploadedAt": 1703520000000
  }
}
```

**Document Types:**
- `certificate_of_incorporation` - Certificate of Incorporation
- `articles_of_organization` - Articles of Organization
- `ein_letter` - IRS EIN Letter
- `proof_of_address` - Proof of Business Address
- `other` - Other supporting document

### kyb.owner_added

Sent when a beneficial owner is added to the KYB application.

```json
{
  "id": "evt_abc123",
  "type": "kyb.owner_added",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "organizationId": "org_xyz",
    "ownerId": "owner_abc",
    "firstName": "John",
    "lastName": "Doe",
    "email": "john@acme.com",
    "ownershipPercentage": 50,
    "verificationStatus": "not_started",
    "createdAt": 1703520000000
  }
}
```

### kyb.owner_verified

Sent when a beneficial owner completes identity verification via Persona.

```json
{
  "id": "evt_abc123",
  "type": "kyb.owner_verified",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "organizationId": "org_xyz",
    "ownerId": "owner_abc",
    "firstName": "John",
    "lastName": "Doe",
    "email": "john@acme.com",
    "verificationStatus": "approved",
    "verifiedAt": 1703520000000
  }
}
```

**Verification Statuses:**
- `not_started` - Verification not yet initiated
- `pending` - Verification in progress
- `approved` - Identity verified successfully
- `denied` - Verification failed
- `needs_review` - Requires manual review

<Note>
  All beneficial owners with 25% or more ownership must complete identity verification before the KYB application can be submitted.
</Note>

## Intent Events

### intent.pending_approval

Sent when an intent is created that requires human approval before the agent can proceed.

```json
{
  "id": "evt_abc123",
  "type": "intent.pending_approval",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "intentId": "int_xyz",
    "customerIntentId": "order-123",
    "cardId": "card_456",
    "agentId": "agent_789",
    "userId": "user_abc",
    "summary": "Order laptop on Amazon",
    "expectedAmount": 125000,
    "expectedMerchant": "Amazon",
    "expiresAt": 1703521800000,
    "status": "pending_approval"
  }
}
```

<Info>
  Respond to this webhook by calling `POST /v1/intents/{intentId}/approve` or `POST /v1/intents/{intentId}/reject` to allow or block the agent's spending.
</Info>

## Auditor Events

Auditors analyze intents and transactions, flagging items that need human review. See [Auditors](/concepts/auditors) for configuration details.

### intent.audit_flagged

Sent when the Intent Auditor flags an intent for human review. This happens when confidence is below the auto-approve/reject thresholds.

```json
{
  "id": "evt_abc123",
  "type": "intent.audit_flagged",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "intentId": "int_xyz",
    "findingId": "finding_abc",
    "cardId": "card_456",
    "agentId": "agent_789",
    "severity": "medium",
    "category": "amount_anomaly",
    "summary": "Amount is 11x agent's historical average",
    "explanation": "This intent requests $499, which is significantly higher than this agent's average transaction of $45. However, the amount is within the card's configured limits.",
    "recommendation": "review",
    "confidence": 0.65,
    "reason": "Low confidence (65%) - needs human judgment"
  }
}
```

<Info>
  Respond to flagged intents by calling `POST /v1/intents/{intentId}/approve` or `POST /v1/intents/{intentId}/reject`.
</Info>

**Severity Levels:**
- `low` - Minor anomaly, likely false positive
- `medium` - Notable anomaly, worth reviewing
- `high` - Significant anomaly, likely needs intervention
- `critical` - Clear fraud indicators, immediate action needed

**Categories:**
- `amount_anomaly` - Amount significantly differs from historical pattern
- `velocity_anomaly` - Too many intents in short period
- `vague_summary` - Intent summary lacks detail
- `suspicious_pattern` - Pattern matches known fraud indicators
- `normal` - No anomalies detected (for auto-approved items)

### transaction.audit_flagged

Sent when the Transaction Auditor flags a transaction for human review. This happens after the risk engine detects anomalies and the AI provides explanation.

```json
{
  "id": "evt_abc123",
  "type": "transaction.audit_flagged",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "transactionId": "txn_123",
    "findingId": "finding_xyz",
    "cardId": "card_456",
    "agentId": "agent_789",
    "severity": "high",
    "category": "cross_pattern",
    "summary": "Multiple anomalies indicate potential unauthorized use",
    "explanation": "This transaction shows three concerning patterns: it was unattested (no credential access recorded), it mismatched the declared intent, and spending rate is 6x the baseline. The combination suggests credentials may have been exposed.",
    "recommendation": "review",
    "confidence": 0.72,
    "riskEngineAnomalies": ["unattested", "intent_mismatch", "spend_spike"],
    "reason": "Low confidence (72%) - needs human judgment"
  }
}
```

**Categories:**
- `explained_anomaly` - Single anomaly explained
- `cross_pattern` - Multiple anomalies form concerning pattern
- `false_positive` - AI believes anomaly is not concerning
- `confirmed_risk` - AI confirms anomaly is genuine risk

<Note>
  The `riskEngineAnomalies` field lists what the rule-based risk engine detected. The auditor adds context and explanation to help humans decide.
</Note>

## Auto-Action Events

These events are emitted when the risk engine automatically takes action on a card or agent.

### card.auto_frozen

Sent when a card is automatically frozen by the risk engine.

```json
{
  "id": "evt_abc123",
  "type": "card.auto_frozen",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "cardId": "card_456",
    "agentId": "agent_789",
    "transactionId": "txn_123",
    "reason": "anomaly_velocity",
    "anomalyType": "velocity",
    "dryRun": false
  }
}
```

**Reasons:**
- `anomaly_duplicate` - Duplicate transaction detected
- `anomaly_velocity` - Velocity limit exceeded
- `anomaly_spend_spike` - Spending spike detected
- `anomaly_unattested` - Unattested spend
- `anomaly_intent_mismatch` - Intent mismatch
- `anomaly_cooldown` - Cooldown violation
- `anomaly_merchant_drift` - Merchant drift detected

### agent.auto_suspended

Sent when an agent is automatically suspended by the risk engine.

```json
{
  "id": "evt_abc123",
  "type": "agent.auto_suspended",
  "organizationId": "org_xyz",
  "createdAt": 1703520000000,
  "data": {
    "agentId": "agent_789",
    "userId": "user_abc",
    "transactionId": "txn_123",
    "reason": "anomaly_velocity",
    "anomalyType": "velocity",
    "dryRun": false,
    "cardsFrozen": 3
  }
}
```

<Warning>
  When an agent is auto-suspended, all of its active cards are also frozen. Review the triggering transaction and anomaly details before reactivating.
</Warning>

<Note>
  If `dryRun: true`, the anomaly was detected but no action was taken. Use dry-run mode to tune your risk policies before enforcement.
</Note>
